# Як користуватись Drawli

Коротка інструкція для батьків. Дитині інструкція не потрібна — застосунок
показує все підказками при першому запуску.

**Відкрити:** https://polukovy.github.io/drawli/

---

## 1. Перший запуск

1. Відкрийте посилання на планшеті.
2. Застосунок питає ім'я — введіть, як дитину звати. Це **не акаунт**: імені
   ніхто не бачить, воно потрібне лише для звертання.
3. Оберіть мову: **Українська** або **English**.
4. Готово. Реєстрації, пароля й пошти не буде.

Наступного разу застосунок відкриється одразу на бібліотеці.

## 2. Встановити на домашній екран

Так Drawli відкривається як звичайний застосунок і працює без інтернету.

**iPad (Safari):** кнопка «Поділитися» → **На екран «Домівка»** → Додати.

**Android (Chrome):** меню ⋮ → **Встановити застосунок**.

Після встановлення застосунок працює в літаку — усе, що дитина відкривала
раніше, лишається доступним.

## 3. Три розділи

Угорі — три великі перемикачі:

| | |
|---|---|
| **Малюю** | Малюнки по кроках: тварини, природа, смаколики, дім, транспорт, фігури, вправи на моторику. Тут же «Чистий аркуш» для вільного малювання. |
| **Літери й цифри** | Українська, англійська та іспанська абетки, цифри 0–9 і числа до 100. |
| **Ігри** | «Склади слово»: дивись на малюнок і збери його назву з літер. |

Другий ряд — жанри (або абетки). В іграх там вибір мови.

## 4. Як малювати

1. Дитина торкається картинки — відкривається вправа.
2. На полотні з'являється **сірий пунктир** — його треба обвести пальцем або
   стилусом. Фіолетова іскринка показує, звідки починати.
3. Праворуч видно **весь малюнок** і скільки кроків лишилось. Тап по цій
   панелі відкриє його на весь екран.
4. Коли крок намальовано, кнопка **«Далі»** засвітиться.
5. Останній крок — розфарбовування: обрати колір і торкнутись малюнка.
6. **«Готово»** → похвала і зірочки.

Малювати «неправильно» неможливо: точність не перевіряється, і застосунок
ніколи не каже, що вийшло погано.

### Інструменти збоку

| | |
|---|---|
| ✏️ | олівець — тонка лінія |
| 🖌️ | пензлик — товста лінія (з Apple Pencil реагує на натиск) |
| 🪣 | заливка — на кроці розфарбовування |
| 🧽 | ластик — стирає лише намальоване дитиною, контур лишається |
| 🎨 | палітра кольорів |
| ↶ ↷ | скасувати / повернути |
| 🗑 | стерти все (повертається стрілкою «вперед») |

## 5. Якщо дитина відволіклась

Нічого не втрачається. Малюнок зберігається сам, кожні кілька секунд і при
виході. Наступного разу на головному екрані буде картка **«Продовжити
малювати?»** з мініатюрою і номером кроку.

## 6. Мої малюнки

Кнопка **«Мої малюнки»** внизу відкриває галерею. Жовта мітка «Триває» — малюнок
не завершено, зелена галочка — готово. Тап по малюнку дає вибір: продовжити,
намалювати ще раз або видалити.

## 7. Прогрес і зірочки

- **+10** за нову вправу
- **+2** за повтор
- **+2** за слово у грі

Кнопка **«Прогрес»** показує, скільки зірочок зібрано і які вправи вже пройдені
в кожному жанрі. Зірочки нічого не купують — це просто відзнака.

## 8. Гра «Склади слово»

1. Розділ **Ігри** → оберіть мову (Українська / English / Español).
2. Дитина бачить малюнок і порожні клітинки.
3. Торкається літер унизу — вони стають на місця. Тап по клітинці повертає
   літеру назад.
4. Якщо слово не склалось, правильні літери лишаються на місцях, решта
   повертається, і застосунок підкаже першу літеру.

П'ять слів за гру.

## 9. Налаштування (⚙ вгорі праворуч)

| | |
|---|---|
| **Ім'я** | змінити звертання |
| **Мова** | Українська / English |
| **Звук** | перемикач (звукові ефекти ще в роботі) |
| **Резервна копія** | «Зберегти» вивантажує файл з усіма малюнками, прогресом і зірочками; «Відновити» завантажує його назад |
| **Скинути прогрес** | стирає все, з підтвердженням |

## 10. Перенести на інший планшет

Дані живуть **лише** на пристрої, тому:

1. На старому планшеті: Налаштування → Резервна копія → **Зберегти**.
   Отримаєте файл `drawli-backup-2026-08-22.json`.
2. Передайте файл на новий планшет (пошта, месенджер, хмарний диск).
3. На новому: Налаштування → Резервна копія → **Відновити** → оберіть файл.
4. Застосунок покаже, що всередині («12 малюнків · 120 зірочок») і замінить
   дані лише після підтвердження.

## 11. Часті питання

**Чи потрібен інтернет?**
Лише для першого відкриття. Далі — ні.

**Чи можна на телефоні?**
Працює, але задумано для планшета: на телефоні все дрібне.

**Що зі збором даних?**
Нічого не збирається: ні пошта, ні аналітика, ні реклама. Малюнки не
залишають пристрій, поки ви самі не збережете файл резервної копії.

**Чи потрібен стилус?**
Ні. Палець працює повністю. Якщо стилус є (Apple Pencil, S Pen), пензлик
реагує на натиск, а долоня на екрані не заважає.

**Дитина натиснула «Стерти все».**
Натисніть стрілку «вперед» (↷) — малюнок повернеться.

**Дитина малює повз контур.**
Так і має бути. Мета — рух руки, а не точність. Розфарбовування все одно
залишиться в межах малюнка.
