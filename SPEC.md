# Drawli — Специфікація MVP

**Продукт:** Drawli — «Вчимося малювати» / «Learn to Draw»
**Платформа:** Web / PWA, tablet-first (iPad, Android-планшет), landscape
**Архітектура:** 100% клієнт. Без бекенду, без БД на сервері, без API.
**Аудиторія:** діти 4–10 років; MVP-фокус 4–7.
**Мови:** English (en), Українська (uk).
**Вхід:** без реєстрації й без Google — дитина просто вводить своє ім'я.
**Деплой:** GitHub Pages, публічний застосунок.

---

## 1. Продуктове ядро

Головний цикл, проти якого оцінюється будь-яка фіча:

```
Обрати → Малювати → Далі → Розфарбувати → Зберегти → Похвалити
```

Якщо фіча ускладнює цикл і не покращує навчання — вона поза MVP.

Принципи:
- **Child first** — великі кнопки (мін. 56×56, головні 64–72), іконки замість тексту.
- **Tablet first** — палець і стилус первинні, миша вторинна.
- **Forgiving** — ніякого «неправильно». Точність ніколи не блокує прогрес.
- **Offline first** — після встановлення працює без інтернету.
- **Privacy first** — жодних персональних даних, реклами, трекерів.

## 2. Технологічний стек

| Шар | Технологія |
|---|---|
| UI | React 18 + TypeScript + Vite |
| Роутинг | React Router |
| Стан застосунку | Zustand |
| Малювання | Canvas 2D + Pointer Events (поза React) |
| Гайди вправ | SVG (окремий шар над canvas) |
| Локальне сховище | IndexedDB через Dexie.js |
| Локалізація | i18next + react-i18next |
| PWA | vite-plugin-pwa (Workbox) |

Заборонено в MVP: backend, PostgreSQL, REST API, Google Login, хмарна синхронізація, AI, платежі, реклама.

## 2.1. Старт застосунку

```
Запуск
  ↓
Читання IndexedDB
  ↓
┌── дані є ────────────────────┐    ┌── даних немає ──────────────┐
│ мова + ім'я + прогрес        │    │ Онбординг:                  │
│ ↓                            │    │ 1. «Як тебе звати?» → ім'я  │
│ Бібліотека вправ,            │    │ 2. Мова (авто з browser)    │
│ вітання «Привіт, Марійко!»,  │    │ ↓                           │
│ картка «Продовжити» якщо є   │    │ запис у settings            │
│ незавершений малюнок         │    │ ↓                           │
└──────────────────────────────┘    │ Бібліотека вправ            │
                                    └─────────────────────────────┘
```

**Ім'я — не акаунт.** Жодного логіну, пароля, email, Google OAuth. Ім'я живе в `settings` в IndexedDB і використовується лише для звертання («Чудово, Марійко!»). Змінити можна в Налаштуваннях. Перевірка «чи є дані» — наявність запису `settings.id = 'app'`.

Модель налаштувань:

```ts
interface AppSettings {
  id: "app";
  childName: string;          // введене ім'я, до 20 символів
  language: "uk" | "en";
  soundEnabled: boolean;
  onboardedAt: string;
}
```

```
  exercise.json, thumbnail.svg, final.svg, step-01.svg …
```

Межа відповідальності:

```
React (вправа, крок, інструмент, колір, навігація)
        ↓ команди

        ↓

```

Координати вказівника **ніколи** не потрапляють у React/Zustand state.

## 4. Моделі даних

```ts
type Difficulty = "VERY_EASY" | "EASY" | "MEDIUM" | "ADVANCED";

interface DrawingDocument {
  version: 1;
  exerciseId: string;
  canvasWidth: number;
  canvasHeight: number;
  actions: DrawingAction[];
}

interface StrokeAction {
  type: "STROKE";
  tool: "PENCIL" | "BRUSH";
  color: string;
  width: number;                       // частка від canvasWidth
  points: { x: number; y: number; pressure?: number }[]; // 0..1
}

interface SavedDrawing {
  id: string;
  exerciseId: string;
  status: "IN_PROGRESS" | "COMPLETED";
  currentStep: number;
  document: DrawingDocument;
  thumbnail?: Blob;                    // WebP 300×225
  createdAt: string;
  updatedAt: string;
}

interface ExerciseProgress {
  exerciseId: string;
  status: "NOT_STARTED" | "IN_PROGRESS" | "COMPLETED";
  currentStep: number;
  startedAt?: string;
  completedAt?: string;
  updatedAt: string;
}
```

**Координати нормалізовані (0..1)** — той самий малюнок коректно рендериться на будь-якій роздільності.

Dexie-схема:

```
drawings:     id, exerciseId, status, currentStep, document, thumbnail, createdAt, updatedAt
progress:     exerciseId, status, currentStep, startedAt, completedAt, updatedAt
settings:     id, childName, language, soundEnabled, onboardedAt
achievements: id, type, earnedAt
```

## 5. Вправа = контент, не код

```json
{
  "id": "ladybug",
  "titleKey": "exercise.ladybug.title",
  "category": "animals",
  "difficulty": "EASY",
  "thumbnail": "/exercises/ladybug/thumbnail.svg",
  "steps": [
    { "id": "body",  "guide": "/exercises/ladybug/step-01.svg", "defaultTool": "pencil" },
    { "id": "head",  "guide": "/exercises/ladybug/step-02.svg", "defaultTool": "pencil" },
    { "id": "wings", "guide": "/exercises/ladybug/step-03.svg", "defaultTool": "pencil" },
    { "id": "spots", "guide": "/exercises/ladybug/step-04.svg", "defaultTool": "pencil" },
    { "id": "color", "mode": "COLORING", "defaultTool": "fill" }
  ]
}
```

Додати нову вправу = `exercise.json` + SVG + два ключі перекладу. **Нуль змін у рушії малювання.**

Шар гайда:
- поточний крок — сірий пунктир, opacity 30–50%;
- попередні кроки — тонкий контур;
- малюнок дитини — обраний колір, opacity 100%.

## 5.1. Каталог вправ і жанри

Ціль — **велика колекція**, яку дитина гортає як книжку наліпок. Жанри в UI показані окремим екраном з великими плитками; усередині жанру — сітка вправ.

| Жанр | id | Вправи | MVP |
|---|---|---|---|
| Моторика | `motor` | лінії, вертикальні лінії, хвилі, зигзаг, петельки, спіраль, дуги, пунктир | 4 |
| Фігури | `shapes` | коло, квадрат, трикутник, прямокутник, овал, серце, зірка, ромб | 4 |
| Тварини | `animals` | сонечко, рибка, метелик, кіт, песик, черепаха, зайчик, ведмедик, пінгвін, слон, жирафа, каченя, сова, їжачок, бджілка, равлик | 3 |
| Природа | `nature` | сонце, хмаринка, веселка, дерево, квітка, гриб, листочок, сніжинка, гора, кактус, зірочка на небі, крапля | 2 |
| Дім і речі | `home` | будинок, замок, парасолька, чашка, годинник, ключик, ліхтарик, ліжко, ваза, скринька | 1 |
| Транспорт | `transport` | машина, автобус, кораблик, ракета, потяг, літак, велосипед, гелікоптер | 1 |
| Смаколики | `food` | яблуко, морозиво, кекс, банан, вишеньки, кавун, піца, цукерка | 1 |
| Свято і фантазія | `fantasy` | подарунок, повітряна кулька, корона, ялинка, чарівна паличка, робот, дракончик, єдиноріг | 0 |

Разом у плані **~86 вправ**. MVP-реліз стартує з **16** (колонка MVP), далі колекція росте пакетами по 8–12 — це чистий контент, коду не торкається.

Маніфест каталогу `public/exercises/index.json` — єдине джерело правди для бібліотеки:

```json
{
  "version": 1,
  "categories": [
    { "id": "animals", "titleKey": "category.animals", "color": "#5FC7C0", "order": 3 }
  ],
  "exercises": [
    { "id": "ladybug", "category": "animals", "difficulty": "EASY",
      "titleKey": "exercise.ladybug.title",
      "thumbnail": "exercises/ladybug/thumbnail.svg", "steps": 6 }
  ]
}
```

Бібліотека вантажить **лише `index.json`** (легкий, кілька КБ). Повний `exercise.json` і SVG кроків тягнуться тільки коли дитина відкрила вправу — інакше 86 вправ × 6 кроків роздують старт.

Правила зростання колекції без болю:

- усі шляхи всередині маніфесту **відносні** — інакше зламається на GitHub Pages з `base: '/drawli/'`;
- `id` вправи незмінний назавжди — він ключ у `progress` і `drawings`;
- нова вправа = папка + рядок у `index.json` + два ключі перекладу;
- вправа, якої немає в `index.json`, не показується, але збережений малюнок по ній не зникає;
- складність усередині жанру зростає: 3–4 кроки для `VERY_EASY`, 6–8 для `MEDIUM`.

### Офлайн і розмір

86 вправ у precache службового воркера = завеликий перший старт. Стратегія:

```
precache      → застосунок, переклади, index.json, мініатюри MVP-вправ
runtime cache → exercise.json і SVG кроків, CacheFirst, при першому відкритті вправи
```

Відкрита раз вправа далі працює офлайн. У Налаштуваннях — «Завантажити всі вправи» для підготовки планшета перед дорогою.

## 6. Правила рушія малювання

| Тема | Правило |
|---|---|
| Події | `pointerdown/move/up/cancel`, `touch-action: none` на canvas |
| Retina | внутрішній розмір = CSS × `devicePixelRatio` |
| Згладжування | сирі точки → інтерполяція → плавний шлях → canvas |
| Олівець | 4–6 px, round cap/join |
| Пензлик | 12–18 px, ширина від `event.pressure` якщо є |
| Ластик | 20–30 px, стирає **лише** дії користувача, не гайд |
| Заливка | пріоритет — заливка SVG-регіону; canvas flood-fill опційно |
| Стилус | `pointerType === "pen"` → палмреджект: ігнорувати `touch` поки перо активне |
| Історія | 1 штрих = 1 undo. Глибина 50. Дії: stroke, erase, fill |

Перехід кроку: `Далі` неактивна, доки не зроблено першу дію. Жодної перевірки точності.

---

## 7. Автозбереження

Зберігати після: штриха, стирання, заливки, зміни кроку, завершення вправи, `visibilitychange → hidden`.
Кнопки «Зберегти» не існує. Мережевих викликів немає.

Відновлення: старт → читання IndexedDB → якщо є `IN_PROGRESS` → картка «Продовжити малювати? 🐞 Сонечко, крок 4 із 6».

## 8. Бекап (заміна хмари в MVP)

```json
{ "version": 1, "exportedAt": "...", "settings": {}, "progress": [], "drawings": [], "achievements": [] }
```

Файл: `drawli-backup-YYYY-MM-DD.json`.
Імпорт: вибір файлу → валідація версії → превʼю («12 малюнків, 120 ⭐») → підтвердження → **Replace**. Ніколи не замінювати дані мовчки.

---

## 9. Локалізація

Визначення при першому запуску: `navigator.language` → `uk-*` → українська, решта → англійська. Ручне перемикання в Налаштуваннях, вибір зберігається локально.
Жодного дитячого тексту хардкодом у компонентах.

---

## 10. Нагороди

Нова вправа завершена → **+10 ⭐**. Повтор → **+2 ⭐**. Зірки локальні. Без магазину, без валюти, без лутбоксів.

---

## 11. Деплой — GitHub Pages

Публічний статичний застосунок, без сервера.

```
git push (main)
      ↓
GitHub Actions
      ↓
npm ci → npm run build → dist/
      ↓
actions/deploy-pages
      ↓
https://<user>.github.io/drawli/
```

Що потрібно врахувати:

| Пункт | Рішення |
|---|---|
| Підшлях репозиторію | `base: '/drawli/'` у `vite.config.ts`; усі шляхи до вправ будувати через `import.meta.env.BASE_URL`, не з `/` |
| SPA-роутинг | GitHub Pages не має fallback → `HashRouter`, або копія `index.html` у `404.html` на етапі build |
| Service worker scope | scope = той самий `base`, інакше офлайн не працює на підшляху |
| Кеш SW | `registerType: 'autoUpdate'`, версіонований precache — інакше діти лишаться на старій версії назавжди |
| Артефакти вправ | `public/exercises/**` потрапляє в `dist` як є і precache-иться |
| HTTPS | Pages дає HTTPS з коробки — обовʼязково для PWA і встановлення на домашній екран |
| Кастомний домен | опційно, через `CNAME` у `public/` |

Workflow `.github/workflows/deploy.yml`: тригер на `push` у `main`, permissions `pages: write` + `id-token: write`, кроки — checkout, setup-node, `npm ci`, `npm run build`, `upload-pages-artifact` з `dist`, `deploy-pages`.

Оскільки бекенду немає, а всі дані лежать у браузері дитини — публічність застосунку не створює ризику для даних. Секретів у бандлі бути не повинно взагалі.

# Фази розробки

Кожна фаза = робочий застосунок. Наприкінці фази — тест на реальному iPad.

### Фаза 0 — Каркас
Vite + React + TS, роутер, Zustand, дизайн-токени (кольори, радіуси, тіні, розміри тач-таргетів), landscape-лейаут.
**Готово, коли:** порожні екрани відкриваються на планшеті, лейаут не ламається.

### Фаза 0.5 — Знайомство і старт
Екран «Як тебе звати?» + вибір мови, запис `settings` в IndexedDB, гілка старту: дані є → бібліотека з вітанням, даних немає → онбординг. Зміна імені в Налаштуваннях.
**Готово, коли:** перший запуск питає імʼя рівно один раз, другий — одразу відкриває бібліотеку з «Привіт, <імʼя>!».

### Фаза 1 — Прототип малювання ⭐ найкритичніша
Canvas, Pointer Events, retina, згладжування, Олівець, Пензлик, Ластик, палітра, Undo/Redo. Без вправ і без сховища.
**Готово, коли:** малювання пальцем і Apple Pencil відчувається природно, без лагів і без рваних ліній. Це критерій, який не можна пропустити.

### Фаза 2 — Вертикальний зріз (Сонечко)
Одна вправа хардкодом: гайди кроків, індикатор кроку, кнопка «Далі», крок розфарбовування, екран завершення.
**Готово, коли:** повний навчальний цикл проходиться від початку до кінця.

### Фаза 3 — Рушій вправ
Винести контент у `exercise.json` + SVG. `ExerciseLoader`, `ExercisePlayer`, бібліотека вправ на головному екрані, категорії.
**Готово, коли:** нова вправа додається без жодної зміни коду рушія.

### Фаза 4 — Локальне збереження
Dexie, схема, репозиторії, `DrawingDocument` з нормалізованими координатами, автозбереження, відновлення незавершеного малюнка.
**Готово, коли:** закрив вкладку посеред кроку 3 → відкрив → малюнок на місці.

### Фаза 5 — Мої малюнки
Галерея, генерація WebP-мініатюр 300×225, деталі малюнка: Продовжити / Намалювати ще раз / Видалити (з підтвердженням).
**Готово, коли:** завершена вправа зʼявляється в галереї з коректною мініатюрою.

### Фаза 6 — EN / UK
i18next, `en.json`, `uk.json`, автовизначення мови, ручне перемикання, локалізовані назви вправ.
**Готово, коли:** повне проходження циклу обома мовами без жодного хардкоду.

### Фаза 7 — Прогрес і зірки
Сторінка прогресу за категоріями, лічильник зірок, нарахування, екран завершення з «+10 ⭐».
**Готово, коли:** зірки нараховуються один раз за першу вправу і +2 за повтор.

### Фаза 8 — PWA
`manifest.json` (standalone, landscape), service worker, precache HTML/JS/CSS/JSON/SVG/іконок/перекладів, встановлення на домашній екран.
**Готово, коли:** авіарежим → відкрив з домашнього екрана → вправа малюється і зберігається.

### Фаза 8.5 — Деплой на GitHub Pages
`base` у Vite, HashRouter або `404.html`, scope service worker, GitHub Actions workflow, перевірка встановлення PWA з живого URL на реальному планшеті.
**Готово, коли:** застосунок відкривається за публічним посиланням, ставиться на домашній екран iPad і працює в авіарежимі.

### Фаза 9 — Бекап
Export JSON, Import з валідацією версії, превʼю, підтвердження Replace, скидання прогресу.
**Готово, коли:** експорт → очищення даних → імпорт → малюнки, прогрес, налаштування і зірки на місці.

### Фаза 10 — Наповнення контентом
16 MVP-вправ (розділ 5.1), маніфест `index.json`, екран жанрів, runtime-кеш SVG, «Завантажити всі вправи».
**Готово, коли:** усі 16 проходяться до кінця, мініатюри коректні, обидві мови повні, нова вправа додається без коду.

### Фаза 12 — Пакети вправ (після MVP)
Колекція росте до ~86 вправ пакетами по 8–12: Тварини+, Природа+, Дім і речі, Транспорт, Смаколики, Свято і фантазія.
**Готово, коли:** пакет додається одним PR з папками вправ і рядками в `index.json`, без змін у рушії.

### Фаза 11 — Поліш і звук
Опційні звуки (тап, завершення, зірка), перемикач Sound ON/OFF, анімації переходів, перевірка тач-таргетів, тест на iPad + Android-планшеті.
